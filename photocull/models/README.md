# Bundled models

`face_recognition_sface_2021dec.onnx` is SFace, a face-recognition model from the
[OpenCV Zoo](https://github.com/opencv/opencv_zoo/tree/main/models/face_recognition_sface),
released under the Apache License 2.0. Goodframes uses it on the Mac to tell which faces in a
shoot belong to the same person. Nothing it computes leaves the shoot's folder.
